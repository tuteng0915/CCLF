# EXP-28 Spec — LangFlow Asymmetric Bootstrapping (Func→Content vs Content→Func)

## 实验背景与动机

**在整体框架中的地位：测试 LangFlow 的空间自举效应是否有方向性——功能词优先承诺是否真的传播帮助内容词。**

EXP-26 证明 LangFlow 有空间自举效应（peak Δ=+21pp, d=5）；EXP-25 证明功能词比内容词更早承诺（Δ=-0.050）。
但两者是否相关？功能词的早期承诺是否**主动传播**帮助周围内容词承诺？

EXP-28 分解自举效应的方向性：
- **func→content（fc）**：已承诺功能词邻居对未承诺内容词的加速效果
- **content→func（cf）**：已承诺内容词邻居对未承诺功能词的加速效果

### 关键发现

1. **不对称性方向与直觉相反**：在悬崖早期（t=0.71-0.82），content→func boost（峰值 +5.4pp）
   **强于** func→content boost（峰值 +2.7pp）。这与 EXP-25 的"功能词先承诺"相矛盾：
   功能词虽先承诺，但它们的承诺对邻近内容词的加速并不比内容词对功能词的加速更强。

2. **两个方向的效应都很弱**（均 < 6pp）：对比 EXP-09 ELF kd_cr 的总体自举效应（+65pp, d=5），
   LangFlow 的非对称效应极为有限。

3. **悬崖后期（t > 0.85）效应消失**：当大多数位置已有承诺邻居时，方向性差异趋零。

4. **原因推测**：LangFlow 功能词的早期承诺主要来自 T5 embedding 空间中功能词的几何特性（低熵、
   高置信度），而非通过显式 decode branch 传播位置信息。因此邻域传播的方向性不依赖词类，
   只依赖"有多少位置已承诺"（通用数量效应）。

### 论文意义

1. **粗到细层级 ≠ 因果方向传播**：LangFlow 中功能词早承诺（EXP-25）和空间自举（EXP-26）都成立，
   但两者并非因果关系。功能词的早期承诺不特别帮助相邻内容词。

2. **ELF KD 的独特价值**：ELF kd_cr 的 decode branch 通过明确的 token 信号传播（自条件化），
   可能产生了真正的定向传播（功能词 → 内容词）。LangFlow 的隐式 attention 传播没有此方向性。

3. **数据量提醒**：cf 组样本量较少（nc ≈ 50-400 vs fc ≈ 500-2500），部分 cf_Δ 估计噪声较大。
   强结论需更多样本（≥200 sequences）。

## ⚠️ 方法论问题（2026-07-22 审查）

### 1. cf > fc 的方向不能解读为因果传播

数据显示 cf_Δ=5.4pp > fc_Δ=2.7pp，即"已承诺内容词邻居对功能词的加速"强于"已承诺功能词邻居对内容词的加速"。Spec 将此解读为"方向性"差异，但这完全可以由 **共因（common cause）** 解释：

**共因解释（无需任何因果传播）**：
- 内容词承诺需要更长时间（EXP-25 确认）→ 已承诺的内容词所在的局部短语"整体难度低"
- 在"整体难度低"的短语中，相邻功能词也恰好先承诺（低难度导致全局快速收敛）
- 结果：cf_Δ 看起来大，但实际是"低难度短语中一切都快速承诺"的共因效应

相同的数据生成过程可以产生任意 fc/cf 方向的差异，取决于词类的基础承诺速率，而不是因果传播方向。

### 2. 效应量本身就不显著

cf_Δ 峰值（+5.4pp）出现在 t=0.796→0.813 时 cf 组中功能词位置约 50-400 个，没有置信区间。+5.4pp 的差距在这个样本量下统计上完全不可区分于 0。

### 3. ELF kd_cr 方向性对比无数据支撑

Spec 写"ELF 的 decode branch 可能产生了真正的定向传播"，但 EXP-09 未分解方向性。这是完全无依据的推测，不应出现在论文结论中。

### 4. T5 geometry 解释不适用 LangFlow

Spec 写"LangFlow 功能词的早期承诺主要来自 T5 embedding 空间中功能词的几何特性"。但 LangFlow 使用 GPT-2 tokenizer 和 GPT-2 embedding，不是 T5。

### 5. 安全结论

- LangFlow 内部：功能词承诺对邻近内容词承诺的条件加速（fc_Δ≈2.7pp）极弱
- cf_Δ 在 spec 数据中看起来更大，但置信区间重叠，且有共因解释
- **不能得出**：
  - ~~"content→func 方向传播比 func→content 更强"~~（无统计显著性，有共因解释）
  - ~~"LangFlow 无方向性因果传播"~~（也没有足够证据证明有）
  - ~~"ELF decode branch 产生了定向传播"~~（无数据支撑的假说）
