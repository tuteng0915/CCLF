# EXP-73 Spec — On-Policy Wave Trajectory Distillation

**Status:** CONDITIONAL / P2  
**Launch condition:** EXP-72 proves that the model uses per-token clocks, but
heterogeneous sampling still has a substantial quality gap.  
**Planned script:** `models/ELF-torch/experiments/probe_elf/train_wave_distill_exp73.py`  
**Purpose:** test whether the remaining failure is exposure bias between
independently noised training states and coupled heterogeneous rollout states.

## Hypothesis

Native WFF training constructs one-step states directly from clean data:

```text
z_i(tau_i) = tau_i x0_i + (1-tau_i) epsilon_i.
```

At inference, however, each token is produced by many attention-coupled
updates while neighboring tokens occupy other local times. The resulting
state distribution need not match the independent forward corruption. Train
the model on states generated by its own wave sampler while retaining a
synchronous teacher as a coherent trajectory reference.

## Teacher trajectory bank

For every initial noise sample, run a frozen healthy teacher on a synchronous
ODE grid and retain

```text
{z_teacher(s), x_hat_teacher(s), v_teacher(s)}.
```

For a local time `tau_i`, linearly interpolate adjacent teacher checkpoints at
position `i`. Assemble the positionwise reference wave state

```text
z_ref[i] = interp(z_teacher[:, i], tau_i).
```

This reference follows individually coherent synchronous trajectories even
though the assembled sequence is heterogeneous.

## Training arms

Use the best EXP-72 architecture and identical initialization:

1. **Off-policy WFF control:** ordinary independently noised heterogeneous
   examples, reproducing the EXP-72 recipe.
2. **Teacher-wave distillation:** train on assembled `z_ref` with local times;
   supervise the next local teacher state and predicted-clean state.
3. **Scheduled on-policy distillation:** unroll the student for `U=4` wave
   steps. With probability increasing `0 -> .5`, replace `z_ref` by the
   student's detached current state before the next supervised transition.

Use losses

```text
L_state = mean_i ||z_student_next[i] - z_ref_next[i]||^2
L_x     = mean_i ||x_hat_student[i] - x_hat_teacher(tau_i)[i]||^2
L_lex   = T^2 KL(p_teacher(tau_i) || p_student[i])
L       = L_state + lambda_x L_x + lambda_lex L_lex + lambda_sync L_sync.
```

In Stage 0, use a 16-step teacher grid and set `lambda_lex=0`: the first gate
tests continuous transition learning without introducing a decoder-dependent
objective. `L_sync` distills the matching synchronous teacher transition for
every batch. Stage 1 increases the teacher grid to 64 steps and adds lexical
KL only if the continuous transition gate succeeds. Freeze loss weights before
inspecting generation. Log every active component; add gradient cosine with
`L_sync` in Stage 1.

## Reversibility and refinement

- No token or continuous state is permanently frozen.
- The wave width decays to zero over the last four solver intervals.
- Include four final synchronous joint-refinement steps during both training
  unrolls and inference.
- Detach between truncated unroll segments initially; full backpropagation
  through the solver is a later ablation only.

## Evaluation and controls

Use the EXP-72 paired panel and add:

- distance from the paired synchronous teacher trajectory by position/time;
- branch endpoint-affinity entropy;
- leader-to-follower margin response;
- `tau_first`, `tau_stable`, revisions;
- quality stratified by prefix/middle/suffix blocks;
- Standard-32, Standard-64, and equal-call synchronous distillation controls.

Stage 0 is a 200-step overfit/sanity run on a small fixed data shard. Stage 1
is a 2,000-step matched pilot at length 128. Do not launch length 1024 or
multi-seed evaluation until the standard sampler and LTR sampler both pass the
shared degeneration and qualitative gates.

## Decision rule

- **Exposure-bias support:** arm 3 improves over both arm 1 and arm 2 on the
  LTR-minus-standard interaction, trajectory distance, and final quality.
- **Teacher path sufficient:** arm 2 works and arm 3 adds little; retain the
  simpler trajectory-distillation method.
- **No rescue:** the model demonstrably uses local times but all three arms
  remain worse than compute-matched synchronous decoding. Close heterogeneous
  clocks as a method direction.
- **Metric-only gain:** PPL improves while degeneration, continuation, or
  revision metrics worsen. Treat as failure.

EXP-73 is the final planned rescue of heterogeneous clocks. A negative result
should redirect method work to EXP-71-style synchronized information flow,
not to a broader schedule sweep.
