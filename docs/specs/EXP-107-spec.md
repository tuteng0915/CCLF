# EXP-107 Spec — Pathwise Shadow Branch Selection

**Status:** DONE / PILOT GATE FAILED
**Purpose:** convert the path-specific causal signal from EXP-102 into a direct
branch decision rather than a sparse trigger-time threshold.

## Method

At Plaid native step 14, construct the fixed one-step 75% top-confidence
anchor and fork the current state into anchor and unmodified control branches.
Advance both through the trigger update plus four released updates using the
same future ancestral-noise stream that the sampler will actually use. At the
decision state, compute unresolved-token entropy response

```text
r = mean_U[H(control) - H(anchor)].
```

Keep the complete anchor branch state when `r>0`; otherwise keep the control
state. Continue the selected state normally with the same scheduled future
noise. This is a short-horizon model-predictive controller:

```text
current state -> {control shadow, anchor shadow}
              -> select lower-entropy branch -> native continuation.
```

It is causal because the future noise is generated by the sampler itself, not
observed from data. It adds five denoiser calls per trajectory relative to the
32-step sampler and one anchor readout plus the paired decision readouts.

## Pilot and gates

- model/scope: Plaid baseline, real 64-token prefix plus 64-token suffix;
- new panel: seed 2029 / offset 9000, `n=64`;
- arms: Standard-32, fixed step-14 anchor, pathwise shadow selection;
- prompts, initial latents, and all native noise are paired;
- no threshold or hyperparameter is selected on seed 2029.

Promote to multi-seed U/C replication only if shadow selection beats the fixed
anchor with paired NLL CI upper bound below zero and satisfies
`Delta D1 >= -.005`, `Delta Rep-4 <= .005`,
`Delta degeneration <= .015`, and `Delta prompt gain >= -.01`. Also report the
fraction choosing anchor, response distribution, C-PPL, shuffled-prompt PPL,
ROUGE-L, D1/D2, repetition, degeneration, and exact model calls.

Implementation:
`experiments/interventions/eval_plaid_pathwise_shadow_exp107.py`.

## Result

The smoke test verifies an exact selector: when the controller chooses anchor,
its output is identical to the fixed-anchor branch; choosing control retains
the Standard branch. On the unopened seed-2029/offset-9000 pilot, it chooses
anchor for `37/64` trajectories (`57.8%`). Results are:

| Arm | C-PPL | prompt gain | ROUGE-L | D1 | D2 | degeneration |
|---|---:|---:|---:|---:|---:|---:|
| Standard | 119.42 | .5131 | .0994 | .5765 | .9499 | .0313 |
| fixed anchor | **82.79** | **.5917** | .0983 | .5728 | .9396 | .0313 |
| pathwise shadow | 89.28 | .5713 | **.1014** | .5655 | .9446 | **.0156** |

Relative to fixed anchoring, shadow selection has paired NLL
`+.0728 [-.0168,.1685]`, D1 `-.0073`, and prompt gain `-.0204`. It fails both
the likelihood and quality gates. Short-horizon response can compare trigger
times weakly, but its sign does not determine whether anchoring is beneficial;
the fixed intervention should be retained.

As a final stop check, response argmax over only steps `8/10/12/14` is evaluated
offline on the five existing banks. Only seed 42 has an NLL interval excluding
zero, and it fails the D1 tolerance; seed 2028 reverses to C-PPL
`85.23 -> 91.33`. Pooled fixed-arm calibration across all five banks already
selects step 14 (C-PPL `85.83`), so do not implement a multi-trigger shadow
beam from this teacher.
